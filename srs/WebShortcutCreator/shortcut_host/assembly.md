 Cкомпилируйте make_shortcut.exe 

Шаги:

1. Проверка наличия Python
Откройте командную строку (cmd) или PowerShell и выполните команду:

DOS
python --version
Если отобразится версия (например, Python 3.10.x или новее), значит Python установлен.

Если появится ошибка «python не является внутренней или внешней командой» или откроется Microsoft Store, значит Python не установлен или не добавлен в переменные среды (PATH).

Также проверьте наличие библиотеки Pillow:

DOS
python -c "import PIL; print(PIL.__version__)"
2. Быстрая установка (если Python не установлен)
Вариант А. Автоматическая установка через winget (самый быстрый способ для Windows)
Откройте PowerShell и выполните команду:

PowerShell
winget install Python.Python.3.12
После завершения установки обязательно перезапустите окно командной строки.


3. Установка обязательной библиотеки Pillow
Для работы с иконками сайтов (.ico) скрипту make_shortcut.py требуется библиотека Pillow. Откройте командную строку и выполните:

DOS
pip install Pillow

Откройте командную строку в папке, где лежит make_shortcut.py.

4. Проверка наличия PyInstaller
Откройте командную строку (cmd) или PowerShell и выполните команду:

DOS
pyinstaller --version
Если выведется версия (например, 6.x.x), значит PyInstaller установлен и готов к работе.

Если появляется ошибка «"pyinstaller" не является внутренней или внешней командой», значит пакет не установлен или его исполнимый путь не добавлен в системный PATH.

5. Установка PyInstaller (если не установлен)
Выполните команду установки через менеджер пакетов pip:

DOS
pip install pyinstaller
После успешной установки проверьте версию еще раз (pyinstaller --version

Выполните команду для сборки EXE :

cmd
pyinstaller --onefile --noconsole --icon="WebShortcutCreator.ico" make_shortcut.py
