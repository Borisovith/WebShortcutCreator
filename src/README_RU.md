Web Shortcut Creator
Инструмент для создания ярлыков веб-страниц в один клик с автоматическим извлечением и привязкой реальных Favicon-иконок сайтов.

В обычных браузерах на базе Chromium (Chrome, Edge, Brave) при перетаскивании ссылки на Рабочий стол создается стандартный .url файл с базовой иконкой браузера. Этот проект полностью обходит данное ограничение.

Как это работает
При создании ярлыка иконка сайта автоматически скачивается, конвертируется и сохраняется в локальную директорию:
%LocalAppData%\WebShortcutsIcons\

После этого абсолютный путь к полученному .ico файлу прописывается в свойствах созданного .url ярлыка.

Ключевые возможности
Автоматическое извлечение иконки: Расширение считывает значок (Favicon) с открытой вкладки в максимальном доступном качестве. Если у сайта нет иконки, автоматически генерируется аккуратная заглушка с первой буквой названия ресурса.

Генерация правильного .ico файла: Python-скрипт конвертирует изображение в полноценный Windows-формат .ico с набором разрешений (16x16, 32x32, 48x48, 64x64) для корректного отображения при любом масштабе интерфейса.

Точная привязка к ярлыку: Скрипт формирует файл .url и жестко фиксирует путь к локальной .ico иконке, благодаря чему ярлык на Рабочем столе сразу получает узнаваемый внешний вид.

Гибкие настройки сохранения: В параметрах расширения можно выбрать:

Мгновенное сохранение в заранее заданную папку по умолчанию (по умолчанию — Рабочий стол).

Интерактивный режим с вызовом системного Проводника Windows для выбора папки при каждом клике.

Важно: После установки расширения закрепите его на панели инструментов (нажмите на значок пазла и нажмите на булавку рядом с расширением). Это гарантирует, что левый клик будет создавать ярлыки, а правый клик будет показывать стандартное меню браузера, избегая случайных скачиваний.
