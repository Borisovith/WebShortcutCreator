Этот скрипт и расширение созданы для того, чтобы в один клик создавать полноценные ярлыки веб-страниц на Рабочем столе (или в любой выбранной папке) с их реальными Favicon-иконками.

При сохранении ярлыка иконка сайта сохраняется в отдельную папку на ПК:
%LocalAppData%\WebShortcutsIcons


Пошаговая инструкция с учетом установки зависимости и описанием настроек расширения. 

### Шаг 1. Установка Python и Pillow через PowerShell
Python и pip удобнее всего развернуть прямо через PowerShell с помощью встроенного пакетного менеджера `winget` — он автоматически пропишет все пути в `PATH`.

Откройте **PowerShell от имени Администратора** и выполните команды:

1. **Установка Python** (автоматически добавляет `python` и `pip` в системный `PATH`): 

winget install -e --id Python.Python.3.12
 
 
> *После установки переоткройте окно PowerShell, чтобы обновились переменные окружения.*


2. **Установка библиотеки Pillow**: 

pip install pillow 

### Шаг 2. Размещение файлов

Скопируйте папку `Tools` в корень диска `C:\`.

Итоговая структура:
* Расширение: `C:\WebShortcutCreator\shortcut_extension\`
* Нативный хост: `C:\WebShortcutCreator\shortcut_host\` 

### Шаг 3. Установка расширения и получение ID

1. Перейдите в Chrome по адресу `chrome://extensions/`.
2. Включите **Режим разработчика** (переключатель в правом верхнем углу).
3. Нажмите **Загрузить распакованное расширение** и выберите папку `C:\Tools\shortcut_extension\`.
4. Скопируйте сгенерированный **ID расширения** (длинная строка из 32 букв на карточке расширения). 

### Шаг 4. Настройка манифеста Native Host

Откройте файл `C:\WebShortcutCreator\shortcut_host\com.shortcut.creator.json` и вставьте скопированный ID вместо `ВАШ_EXTENSION_ID`:
 
{
  "name": "com.shortcut.creator",
  "description": "Desktop Shortcut Creator Native Host",
  "path": "C:\\WebShortcutCreator\\shortcut_host\\run.bat",
  "type": "stdio",
  "allowed_origins": [
    "chrome-extension://ВАШ_EXTENSION_ID/"
  ]
}

### Шаг 5. Регистрация хоста в реестре Windows

Запустите файл `register.reg` двойным кликом и подтвердите добавление данных в реестр Windows. 

### Шаг 6. Настройка поведения и путей в расширении

Кликните правой кнопкой мыши по иконке расширения на панели Chrome и выберите **Параметры** (или нажмите «Детали» $\rightarrow$ «Настройки параметров» на странице `chrome://extensions`).

На странице настроек доступны два режима сохранения:

* **Спрашивать папку каждый раз при сохранении** — при клике на иконку будет открываться стандартное окно системного проводника для выбора папки назначения.
* **Сохранять в папку по умолчанию** — ярлыки сразу сохраняются в указанный каталог. Чтобы задать путь, нажмите кнопку **«Обзор...»** и выберите нужную папку (по умолчанию используется Рабочий стол).
