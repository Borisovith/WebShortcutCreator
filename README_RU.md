# WebShortcutCreator

[![Platform](https://img.shields.io/badge/Платформа-Windows-0078d7)](https://www.microsoft.com/windows)

**Создание ярлыков веб-страниц с настоящей иконкой сайта на Windows в один клик**  
Это расширение для Chrome + локальный модуль Native Messaging, который позволяет создавать ярлыки рабочего стола для любого сайта с его оригинальной иконкой (favicon) прямо из панели инструментов браузера. Поддерживаются Chrome, Edge, Opera, Brave, Vivaldi и другие браузеры на базе Chromium.

---

## ? Возможности
- **Создание в один клик** — нажмите на иконку расширения на любой странице, чтобы мгновенно создать ярлык.
- **Вшивание настоящей иконки** — извлекает оригинальный favicon сайта и встраивает его прямо в ярлык Windows (`.url`).
- **Гибкие режимы сохранения** — выбор папки каждый раз перед сохранением или мгновенное сохранение в папку по умолчанию (например, на Рабочий стол).
- **Локальный хост-модуль** — безопасное создание ярлыков в фоновом режиме через лёгкий скомпилированный исполняемый файл.
- **Поддержка множества браузеров** — инсталлятор автоматически настраивает Native Messaging для Chrome, Edge, Opera, Brave и Vivaldi.
- **Удобный инсталлятор (Inno Setup)** — `setup.exe` автоматически регистрирует хост-модуль в реестре Windows и поддерживает стандартное удаление через «Установку и удаление программ».

---

## ?? Быстрый старт (Настройка в два шага)

### Шаг 1: Установите расширение
1. Установите **Web Shortcut Creator** прямо из [Интернет-магазина Chrome](https://chromewebstore.google.com/detail/npahemdaconbjbbgojmmegikfnnkgjbc?utm_source=item-share-cb).
2. **Закрепите расширение** на панели инструментов: нажмите на иконку пазла (меню расширений) и нажмите иконку булавки рядом с "Web Shortcut Creator".

> **Важно:** Закрепление гарантирует корректную работу контекстного меню по правому клику.

### Шаг 2: Установите локальный хост-модуль (Native Host)
1. Скачайте архив последнего релиза со страницы [Releases](https://github.com/Borisovith/WebShortcutCreator/releases).
2. Распакуйте архив и запустите `setup.exe`.
3. Следуйте подсказкам мастера установки Inno Setup — он автоматически зарегистрирует хост-модуль в реестре Windows для ваших Chromium-браузеров.

## ?? Настройка
Нажмите правой кнопкой мыши по иконке расширения и выберите **Параметры** (или откройте их через менеджер расширений):
- **Спрашивать каждый раз** — при создании ярлыка будет появляться стандартное окно выбора папки.
- **Сохранять в папку по умолчанию** — ярлыки создаются мгновенно в выбранном каталоге (по умолчанию: `Рабочий стол`).

## ??? Системные требования
- Windows 7 / 8 / 10 / 11
- Любой браузер на базе Chromium (Google Chrome, Microsoft Edge, Brave, Opera, Vivaldi)
- Установка Python не требуется — хост-модуль и инсталлятор представляют собой готовые исполняемые `.exe` файлы.

---

## ?? Решение проблем
- **Ярлык не создаётся?** > Убедитесь, что вы запустили `setup.exe` после установки расширения.
- **Проверка реестра** > Проверьте, существует ли ветка реестра `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.shortcut.creator`.
- **Правый клик вызывает скачивание файла?** > Убедитесь, что иконка расширения закреплена на главной панели инструментов браузера.
